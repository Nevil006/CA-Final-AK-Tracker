CA Final FR Tracker PWA
=======================

Files:
- index.html: app
- manifest.webmanifest: installable app metadata
- sw.js: offline cache
- icon.svg: app icon

To install as an Android app:
1. Upload the contents of this folder to a static HTTPS host (GitHub Pages is free).
2. Open the resulting HTTPS site in Chrome on Android.
3. Chrome menu (⋮) > Install app / Add to Home screen.
4. Open the installed app. Your progress is stored locally on that device.

Important:
- HTTPS hosting is required for PWA installation and offline service-worker support.
- Data is stored in the browser on each device, not automatically synced.
- Use Backup > Export backup on one device and Import backup on another.
- The initial state marks every part before Lecture 29 Part 1 as watched, based on the user's stated progress. Check and correct if needed.
- The five topics without durations in the PDF have blank estimates. Enter hours when known.
